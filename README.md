## ADHDed-Planner-Maker

# 목적
1. 자발적 학습 및 계획 수립이 서투른 나를 위한 플래너 기획
2. adhd인들 누구나 쉽게 원하는 요소를 포함 / 제거할 수 있는 플래너 파일 생성

# 포함된 기능
1. 월간 / 주간 / 일간 플래너 동적 생성
2. 양력 기준 고정된 공휴일들 및 대체 공휴일 판별 함수 구축
3. 입력된 방향 키 값에 따라 전후 페이지 이동

# 앞으로 추가될 수 있는 기능(미정)
1. 음력 기준 공휴일들 판별 함수
2. 시작 요일 변경 기능
3. 출력할 기간 및 포함할 플래너 양식 수정 기능
